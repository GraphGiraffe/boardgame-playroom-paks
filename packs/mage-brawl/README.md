# Стихийная потасовка (mage-brawl) · 0.2.2

Опубликованный пак коллекции 0.8.3 для приложения 0.19.3, engineApi 4 / viewApi 3. Имя Mage Brawl сохранено в техническом ID; пользовательское название — «Стихийная потасовка».

2–8 игроков одновременно планируют действия. По умолчанию два действия разных типов, четыре карты и четыре здоровья (авто), две жизни, скрытые руки. Сначала движения, затем атаки; внутри каждой фазы Воздух → Земля → Вода → Огонь. Второе действие следует после полного первого цикла; погибший его не выполняет. Настройки количества действий, стартовой руки, здоровья и жизней независимы.

Убийство увеличивает лимит руки на один; возрождение добирает до текущего лимита. Непотраченные ульты переходят убийце и могут накапливаться. Потерянные жизни/здоровье остаются контурами; доступные базы подсвечиваются. Справка руки содержит порядок действий и схемы всех стихий, подсказка расположена под рукой в обеих ориентациях.

`domain/` содержит правила и ботов; `presentation/` — авторизованные сцены; `view.js`, `styles.css`, `locales/` — интерфейс; `manifest.json` — версия и настройки. Правила и сцены не получают DOM. Изменения публикации фиксируются в CHANGELOG коллекции, исходные версии остаются неизменными.
