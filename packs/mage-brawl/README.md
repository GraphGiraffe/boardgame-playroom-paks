# Стихийная потасовка

Игра для 2–8 участников с одновременным тайным планированием. Движения выполняются перед атаками, в порядке Воздух → Земля → Вода → Огонь. Второй выбранный ход выполняется после полного первого цикла. Есть классический режим и 2–4 команды; огонь по своим включён.

Стихийная клетка добавляет +1 к атаке стоящего на ней мага указанной стихией и +1 к получаемому им урону этой стихии. Бонусы атакующего и цели складываются; щиты и иммунитеты сохраняют действие. Боты используют тот же расчёт урона и прогнозируют последовательность собственных карт по публичному состоянию.

`domain/` содержит детерминированные правила и ботов, `presentation/` — разрешённые сцены, `view.js`, `styles.css`, `locales/` — интерфейс. [Манифест](manifest.json) задаёт точную версию и параметры, [локаль](locales/ru/game.json) — книгу правил. [Механики команд, жизней и сжатия](../../docs/MAGE-BRAWL.md), [контракт правил](../../docs/PLAYER-RULES.md). Исторические [печатные материалы](../../docs/design/mage-brawl-rulebook/README.md) сохраняют исходную редакцию; действующие правила определяются паком.
