# Звуки Морского боя

Оригинальный синтез PlayRoom, без сторонних записей. Пересобрать: `python3 scripts/generate_battleship_sounds.py`.
Моно WAV PCM16, 22050 Гц. Исходники и файлы распространяются по лицензии репозитория.
`start` — короткая сирена, `miss` — всплеск, `hit` — удар, `sunk` — погружение.
`sea.sunk` заменяет `sea.hit`; при скрытом потоплении всегда звучит обычное попадание.
Все файлы встроены в sounds.js, сеть во время игры не нужна.
