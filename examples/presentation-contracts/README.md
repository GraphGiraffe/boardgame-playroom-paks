# Исполняемые примеры компонентного контракта

Это исполняемые учебные модули, не устанавливаемые паки и не альтернативное ядро.
Запуск из корня коллекции:

```sh
node examples/presentation-contracts/sequential.cjs
node examples/presentation-contracts/simultaneous.cjs
node examples/presentation-contracts/board.cjs
```

`sequential.cjs`: две одинаково нарисованные карты имеют разные физические ID;
выбран только один экземпляр. Рука использует canonical HandLayout, раскрытие
ссылается на публичную EntityRef. Возвращаемый HandLayout — данные компоновки,
не готовый HTML-контейнер; в паке контейнер создаёт `H.hand` (пример UNO).

`simultaneous.cjs`: решения проверяются до записи, отмена повышает revision,
готовность раскрывается всем одновременно после durable commit. `resolve`
вызывается только в authority и возвращает закрытые команды только правилам;
публичные эффекты строятся из результата разрешения, не из этих команд.
Порядок разрешения и победа здесь намеренно отсутствуют — это правила игры.

Полные интеграции: UNO и Mage Brawl. Устанавливаемый минимальный пример
проекций: `../private-counter`. Версии текущего API определяют manifest.json;
локальный кандидат использует engineApi 4 и viewApi 3.

`board.cjs`: публичные исходная и итоговая сцены с произвольным namespace
`stone`, движением одного экземпляра и удалением другого. Это фрагмент сцены:
полный пак добавляет всех участников и метрики. Web host захватывает геометрию
по этим ссылкам до commit; имя класса и префикс фишки не определяют анимацию.
Скрытую руку нельзя включать в публичные board objects.
