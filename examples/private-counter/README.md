# Минимальный пак с личной информацией

Это учебный пример контракта, не шестая игра основной коллекции. Общий счётчик и закрытая цель показывают разницу между audience и surface. Цель не влияет на победу; последняя здесь намеренно упрощена. Все действия задаются правилами, view только отображает проекцию.

Для проверки вместе с веткой приложения:

```sh
node ../boardgame-playroom/dev/server.cjs --packs-dir examples --game private-counter --players 2
```

Откройте напечатанные общий и личные адреса в разных окнах. В JSON общего клиента и другого игрока нет закрытого значения. История также фильтруется.

Сборка установочного JSON отдельно от обязательных пяти игр:

```sh
python3 build.py --include-examples
```

Сначала опишите `project`, затем представления. Не передавайте `Session.export()` клиентам. Для production-пака отдельно проработайте правила, приватность, сохранения, дизайн и тесты.
