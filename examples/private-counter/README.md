# Учебный пак private-counter

Минимальный пример API движка 3 и UI 2, версия 0.4.0. Общий счётчик виден всем; закрытая цель — только владельцу. Цель не влияет на упрощённую победу. Правила задают все действия, view отображает уже разрешённую проекцию.

Из корня репозитория паков:

```sh
python3 build.py --include-examples --output-dir dist/authoring
```

Установите `dist/authoring/private-counter-0.4.0.playroom-pack.json` через «Паки игр» приложения. Пример не входит в обычную коллекцию двенадцати игр. Проверьте два viewer и публичный Стол: чужая цель отсутствует в JSON и истории, а не только скрыта CSS.

[Руководство автора](../../docs/AUTHORING.md) содержит следующий шаг: новая игра с собственными ID/версией и проверками. Пример не копирует ядро и не требует отдельного production-сервера.
