# Закрытый сигнал

Пример для SDK с общим кубиком, двумя закрытыми решениями и дедлайном. Правила
используют `shared/domain/decision-window.js`. До раскрытия хост видит полный
выбор, Стол получает только готовность, а игрок может увидеть свой ответ.
Пак получает время от хоста через `advance(position, now)`. Если оба готовы,
решения раскрываются сразу. По дедлайну неотправленный выбор даёт ноль очков.
Кубик в строке статуса описывает общий `DieAsset`. Правила передают выпавшую грань, а сцена задаёт показ без анимации броска.

Сценарии в `sdk/scenarios.json` проверяют обе причины раскрытия, границу
дедлайна, повторный и поздний ввод. Пример собирается отдельно от каталога игр.
