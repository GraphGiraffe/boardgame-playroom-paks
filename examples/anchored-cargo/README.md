# Перевозка груза

Пример профиля SDK `anchored-board-v1`. Плоская зона `slots` ссылается на
носитель через `anchor` и задаёт вместимость через `capacity`. Фишки адресуются
собственными ID. Движок показывает их внутри носителя и перемещает вместе с ним.
Представление использует `TileAsset` для носителей и `TokenAsset` для груза. Якоря зон ссылаются на ID, выданные тем же профилем размещения.

Правила разрешают погрузить фишку и начисляют очко за один переход. Правило
доставки требует заполнить оба места. Представление привязывает полученные
команды к зонам. Профиль `anchored-orientation-v1` показывает поворот
гружёного тайла на месте и во время перемещения. При повороте меняется поза
носителя, а груз сохраняет адрес слота. Сценарий `load-travel-deliver`
проходит погрузку, поворот, перенос, передачу хода и завершение партии.

В режиме «Перегрузка» выберите первую погружённую фишку, затем свободный
слот принимающего тайла. Принимающий тайл движется одновременно с грузом.
Груз сохраняет ID, поэтому интерфейс перемещает тот же элемент и показывает
один перелёт. Сценарий `pass-to-second-carrier` проверяет доступность передачи,
адрес после хода и сохранение счёта.

Пример собирается отдельно от основной коллекции.
