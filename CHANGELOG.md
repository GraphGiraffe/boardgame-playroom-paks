# Изменения

## 0.1.0

Первая независимая поставка пяти паков: UNO, домино, дурак, шашки, змеи и лестницы. API движка 1, версия состояния 1. Включены текущие правила, боты, настройки, адаптивные сцены, поддержка общих жестов, событий и звука; UNO содержит индивидуальный сигнал объявления.

Игры собираются в отдельные `.playroom-pack.json`. Все ресурсы находятся внутри контейнера, приложение не требуется пересобирать для установки или обновления игры.
