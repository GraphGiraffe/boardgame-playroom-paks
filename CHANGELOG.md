# История изменений

## 0.5.0 · для PlayRoom 0.16.0

- Лудо 0.1.4: гарантированный выход одной фишки завершает ход даже при двух или трёх кубиках; аватары используют стандартные светлые цвета.
- Акулина 0.1.3: закрытая передача и её звук доступны только двум участникам, публичная пара остаётся открытой.
- Ятзи 0.1.3: удержанный кубик можно освободить перед третьим броском; подсказка и область управления сохраняют размер.
- Морской бой 0.1.3: отдельные силуэты кораблей по числу палуб, красный ноль, центрирование и полная видимость поля после перехода.
- Шашки 0.3.4 и Змеи и лестницы 0.3.7: светлые стандартные аватары, цвета шашек и фишек на поле сохранены.

## В разработке

- Лудо 0.1.3: выбор фишки и клетки назначения вместо выбора кубика. Все оставшиеся кубики участвуют в подсветке; одинаковые цели объединены. Цвета результата, точки маршрута, рамка доступного броска и серые использованные кубики. Выбранная фишка сохраняется между перемещениями.

## 0.5.0-preview.3 · для PlayRoom 0.16.0-rc.4

- Дурак 0.4.2: обычный, подкидной и переводной; 36/52/54 карты, отдельный тип джокеров только для 54 карт; до первого вышедшего или последнего дурака; обмен младшего козыря, частичный отбой обычного и корректный добор.
- Морской бой: запрет касаний, объявление потопления с отметкой окружения, счётчики остатка флота, бот по открытым данным и личное переключение поля на чужой ход. Четыре синтезированных звука с исходниками; потопление заменяет попадание.
- Ятзи: равные колонки с аватарками и закреплёнными названиями/итогами; отдельные сигналы обычных, особых комбинаций и Ятзи. Пексесо различает пару и несовпадение; Рыба озвучивает публичный комплект.
- Новые версии данных Лудо/Акулины/Морского боя — 2, Дурака — 3. Прежние опубликованные версии не перезаписываются.

# Изменения

## 0.4.0-preview.1 — кандидат

- UNO 0.4.0; домино, дурак, шашки и змеи 0.3.0. Все пять паков передают playerContent и поверхности table/player, а приложение располагает сведения и руки.
- Дурак передаёт группы stock/play. Убраны постоянные подсказки шашек и змей; бросок выполняется нажатием кубика.
- Инициализация поддерживает случайного/назначенного первого игрока, согласованную очередь и роли; светлые шашки принадлежат назначенному первому игроку.
- Геометрия игровых объектов принадлежит паку, общий UI — приложению. Пример private-counter обновлён до 0.3.0. Публикация этой коллекции пока не выполнена.

## Не выпущено — API интерфейса 2

- Все пять паков предоставляют field/hand/participants/status/actions/auxiliary; компоновка принадлежит приложению.
- UNO 0.3.0, домино/дурак/шашки/змеи 0.2.0; коллекция 0.3.0-preview.1.
- Убраны CSS-правила размещения общих компонентов и изменения шапки приложения; старый viewApi не поддерживается.
- Учебный private-counter также переведён на API 2.

## Не выпущено — UNO 0.2.1 и общие события интерфейса

- UNO `0.2.1` сохраняет `engineApi: 1` и `stateVersion: 1`, прежние действия и штрафы, но добавляет необязательную подпись `targetPrompt: "UNO!"` для двухтапового обвинения на токене/руке игрока.
- События ручного и автоматического UNO, раннего выкрика, успешного обвинения и ложного обвинения передают короткие общие метки `notice`. Звук `uno.call`/`penalty` остаётся данными пака/ядра.
- Текст правил объясняет «коснитесь имени или руки соперника, за 2 секунды подтвердите UNO!»; ложное обвинение: +2 карты обвиняющему, успешное: +2 карты пропустившему, ранний выкрик без штрафа.
- Старые опубликованные версии не изменены. Для нового интерактивного выделения требуется приложение с `PlayroomPlayerTarget`/`PlayroomGameFeedback`; старый app API 1 сохраняет базовые ходы и правила.

## Не выпущено — коллекция 0.2.0-preview.1

- Дурак 0.1.1: пропорциональная графика, крупные ранг/масть компактной версии.
- Учебный private-counter 0.1.0 в examples; сборка по --include-examples, вне основной пятёрки.
- Домино, шашки и змеи остаются 0.1.0; опубликованные версии не перезаписаны.

- Команды Codex Cloud для самостоятельной проверки паков и совместного прогона с checkout приложения.
- AGENTS.md, инструкция окружения и CI на тех же командах. В том предыдущем подготовительном этапе игровые версии не изменялись.

## 0.1.0

Первая независимая поставка пяти паков: UNO, домино, дурак, шашки, змеи и лестницы. API движка 1, версия состояния 1. Включены текущие правила, боты, настройки, адаптивные сцены, поддержка общих жестов, событий и звука; UNO содержит индивидуальный сигнал объявления.

Игры собираются в отдельные `.playroom-pack.json`. Все ресурсы находятся внутри контейнера, приложение не требуется пересобирать для установки или обновления игры.
