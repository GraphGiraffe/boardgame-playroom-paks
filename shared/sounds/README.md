# Стандартные звуки

`standard-sounds.json` содержит 26 стандартных процедурных звуков приложения 0.18: ноты, интервалы, формы волны, уровни и подписи для `playroom/core/audio.js`. Это исходные звуковые ассеты, пригодные для `TabletopAudio.registerPack()`. Приложение проигрывает их через Web Audio без сетевой загрузки и без дублирующих WAV; в следующих обновлениях меняйте этот канонический JSON и синхронизируйте приложение сборщиком при изменении звучания.

Личные записи игр остаются в своих паках: `packs/uno/assets/uno-call.wav`, `packs/battleship/assets/{start,miss,hit,sunk}.wav`. Встроенные `sounds.js` используют те же записи; исходные WAV сохраняются для повторного применения. Уровень громкости, наложения и `reduced motion` регулирует приложение, а не файл ресурса.

## Семантика действий

Пак публикует публичный факт по своим правилам; presentation добавляет `feedback: {kind, player}`. `skip` — вынужденный пропуск, `pass` — объявленный пас, `discard` — «бито», `take` — взять со стола, `draw` — добрать из колоды, `reverse` — сменить направление. Пропуск использует `attack.skip`, направление — `reverse`, остальные — одноимённые стандартные звуки. Пак может уточнить звук составного действия (например, UNO +2/+4), сохранив визуальный skip для адресата.

Приложение выбирает один основной звук на revision: итог партии > пропуск > штраф > UNO > направление/взятие > бито > пас > взятие со стола > добор > обычное действие. Равный приоритет сохраняет первый факт. Разные действия звучат последовательно; сигнал начала своего хода не накладывается на активный звук. Повторный snapshot/ACK и восстановление истории не повторяют оповещение.

Карточка пропустившего игрока кратко краснеет и встряхивается 700 мс без изменения размеров. При reduced motion остаётся неподвижная красная подсветка. Обычный конец хода и уже финишировавшие игроки не считаются пропуском. В UNO стрелка скрыта при двух активных игроках; reverse действует как skip. В Лудо skip возникает только когда после броска нет ни одного действия; неиспользуемый остаток после сделанного перемещения — не отдельный пропуск. В Домино это отсутствие легальной выкладки и доступного добора; в Дураке взявший карты пропускает право следующей атаки. В Змеях и лестницах выход за финиш возвращает фишку по правилам, а не создаёт искусственный skip.
