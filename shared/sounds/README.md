# Стандартные звуки

`standard-sounds.json` содержит все 23 стандартных процедурных звука приложения 0.17.3: ноты, интервалы, формы волны, уровни и подписи из `playroom/core/audio.js`. Это исходные звуковые ассеты, пригодные для `TabletopAudio.registerPack()`. Приложение проигрывает их через Web Audio без сетевой загрузки и без дублирующих WAV; в следующих обновлениях синхронизируйте JSON с `core/audio.js` при изменении стандартного звучания.

Личные записи игр остаются в своих паках: `packs/uno/assets/uno-call.wav`, `packs/battleship/assets/{start,miss,hit,sunk}.wav`. Встроенные `sounds.js` используют те же записи; исходные WAV сохраняются для повторного применения. Уровень громкости, наложения и `reduced motion` регулирует приложение, а не файл ресурса.
