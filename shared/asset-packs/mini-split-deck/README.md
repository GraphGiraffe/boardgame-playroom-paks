# Мини: номинал / масть · 0.1.0

Общий скин `card-face:mini-split`, 5:7. Верхняя половина — номинал, нижняя — масть. Цвета и материал наследуются от темы; прежние лица и mini-cards сохранены. `PlayroomMiniSplitDeck.face({rank,suit})` принимает уже локализованные знаки и возвращает SVG без интерактивности. Специальный `main` и скрытые карты обрабатывает основной renderer. Джокеры сохраняют различимые цвет и подпись общей карты.

Пакуется отдельно и встраивается offline. В пасьянсах исходный скин — mini-split; явный Основной пользователя и индивидуальный выбор имеют приоритет. Настройки оформления не входят в состояние игры.
