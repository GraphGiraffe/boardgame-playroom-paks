# Мини-карточки номиналов

Переиспользуемый набор `playroom-asset-pack`, геометрия 5:7. Подключение: `sharedUi: true`, `sharedAssetPacks: ["mini-cards"]` в манифесте игры. Builder встраивает объявленные scripts и styles, включая offline JSON и самостоятельный HTML.

`PlayroomMiniCards.card({rank, id, label, className})` возвращает неинтерактивную карту с доступной подписью и необязательным якорем `card-${id}`. Значение rank — уже локализованная буква или цифра; игровой смысл остаётся в паке. Лицевая поверхность берётся из общего компонента обычных карт, палитра — из material.card.

Ширина 24 px, скругление 3 px, торец 1 px и мягкая тень. Номинал слева сверху; «10» оптически смещено влево. Контейнер задаёт одну прокручиваемую строку высотой 36 px с `data-card-overlap="14"`; общий адаптер приложения вычисляет одинаковое перекрытие. Набор не определяет рассадку, размер поля или правила игры.
