# Колода персонажей

48 semantic characters × две копии. Семейство character-face: minimal («Стандартный», по умолчанию) и simple («Простой»). Арты и правила используют прежние semantic ID. Аватары выбираются отдельно от колоды. Лицо карты бежевое, 5:7.

Канонические рабочие наборы: characters-minimal и characters-simple. Подробный набор characters сохраняется отдельно как архивный ресурс, но не входит в зависимости колоды или runtime Пексесо. SVG-оригиналы и генератор хранятся в исходниках.
