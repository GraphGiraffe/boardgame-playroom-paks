# Персонажи-стикеры

Отдельный набор ассетов 0.1.1. Персонажи и колода используют одни идентификаторы, без изменения цвета при смене темы. Прозрачные персонажи на квадратном холсте; карточки имеют пропорции 5:7 и белую основу.

Runtime: 256×256 WebP с alpha. Исходные PNG 512×512 сохраняются в images/ и source ZIP; они не входят в устанавливаемые asset ZIP.
