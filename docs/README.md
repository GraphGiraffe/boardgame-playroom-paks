# Разработка паков: карта ресурсов

Документация помогает найти исходники, изменить игру и проверить результат. Начальная точка — [руководство автора](AUTHORING.md); команды сборки и порядок внесения изменений — в [CONTRIBUTING](../CONTRIBUTING.md).

| Задача | Ресурс |
|---|---|
| Создать или изменить игру | [Руководство автора](AUTHORING.md), [архитектура](ARCHITECTURE.md), `packs/<id>/` |
| Использовать общие компоненты | [Контракты компонентов](COMPONENT-SDK.md), [примеры](../examples/presentation-contracts/README.md), `shared/` |
| Найти изображения, фишки и скины | [Типы элементов](PIECE-TYPES.md), `shared/assets/`, `docs/design/` |
| Подготовить правила для игрока | [Правила](PLAYER-RULES.md) |
| Добавить подсказки и обучение | [Действия игрока](TUTORIAL-ACTIONS.md) |
| Разобраться в Стихийной потасовке | [Особенности реализации](MAGE-BRAWL.md) |
| Проверить упаковку и ассеты | [Инварианты](DEVELOPMENT-REGRESSIONS.md) |
| Проверить условия использования материалов | [Лицензирование](../LICENSING.md) |

`manifest.json` задаёт метаданные пака; `manifest.js` генерируется сборщиком. Общие исходники принадлежат `shared/`, а каждый готовый пак содержит нужные ему runtime-ресурсы. Дизайн-материалы в `docs/design/` — референсы и исходные варианты, не список файлов для включения в пак.

Сейчас используются engineApi 4 и viewApi 3. Авторство через SDK, изолированное исполнение, new/adopt и общий compiler описаны в [руководстве автора](AUTHORING.md). Source-export, устанавливаемый пак и опубликованная поставка проверяются отдельно.
