# Подсказки: действия игрока

Как подключить каталог, распознать события и версионировать цели — [руководство обучения приложения](https://github.com/GraphGiraffe/boardgame-playroom/blob/main/docs/TUTORIALS.md). Владение файлами — [архитектура паков](ARCHITECTURE.md).

Пак определяет список действий для обучения и их ревизии. Освоенные действия хранятся в сохранениях пользователя отдельно для каждого пака и сохраняются между партиями. Нажатие и перетаскивание, приводящие к одной успешной команде, закрывают одинаковый пункт. Само появление дамки, дубля или ульты не закрывает обучение их использованию. Недоступные в выбранном режиме или ещё не возникшие ситуации не показываются; они не мешают другим подсказкам. При завершении партии подсказки прекращаются, но неосвоенные действия ожидают подходящей ситуации в следующих партиях. Отключённое обучение не отслеживает действия.

| Пак | Самостоятельные действия |
| --- | --- |
| Стихийная потасовка | Движение, атака, ульта; первая карта и подтверждение; вторая карта и подтверждение; поворот; открытие справки; отмена плана; база возрождения; открытие руки для награды и выбор карты |
| UNO | Выбор карты, выкладка, выбор цвета чёрной карты, добор, пропуск, открытие справки; объявление UNO, выбор карточки соперника и указание на забытое UNO только в подходящем окне |
| Лудо | Первый/повторный бросок после шестёрки; выход по шестёрке и гарантированный выход; выбор/ход фишкой; бросок и ход за напарника после собственного финиша |
| Морской бой | Выбор размера, установка, выбор установленного корабля, поворот, перемещение, возврат, готовность, выстрел, ручной переход на своё поле и поле соперника, кнопка автопереключения |
| Косынка | Выбор и перенос карт, открытие колоды, переворот, возврат сброса, сбор в дома, отмена, кнопка подсказки |
| Паук | Выбор и перенос карт, раздача нового ряда, отмена, кнопка подсказки |
| Дурак | Выбор карты, атака/подкидывание, защита, перевод, взятие, «Бито», подтверждение/отмена выкладки, обмен козыря |
| Пексесо | Первая и вторая карты — разные пункты, независимо от индексов выбранных карт |
| Акулина | Выбор соперника, выбор карты из открытого окна его руки |
| Спроси рыбу | Выбор конкретной карты нужного номинала → выбор соперника; автоматический добор не является действием обучения |
| Ятзи | Первый бросок, переброс, удержание и освобождение кубика, запись комбинации |
| Змеи и лестницы | Бросок, выбор кубика для перемещения, повторный бросок после дубля, изменение длины хода на особой клетке |
| Домино | Выбор костяшки, конец цепочки, добор с базара, пропуск |
| Шашки | Выбор шашки, перемещение, взятие, продолжение серии; выбор дамки и её дальний ход |
| Крестики-нолики | Выбор свободной клетки |

Автоматические эффекты (взрыв, лестница, превращение в дамку, получение штрафа, автоматическая смена игрока) сами не являются нажимаемыми действиями. Если эффект открывает дополнительное решение, для него нужен отдельный пункт. Подсказка не требует создавать редкую ситуацию специально и не заставляет отменять уже принятый ход.

Контракт и жизненный цикл описаны в [COMPONENT-SDK](COMPONENT-SDK.md#semantic-tutorial-checklist-optional-host-extension). Изменяя команды пака, сверять этот список, селекторы фактического UI и условия `match`. Предыдущая схема «первый ход завершился — всё обучение завершено» больше не используется.


Проверка порядка (preview.19): в Рыбе выбор соперника доступен только после выбора карты, ещё присутствующей в legal actions. Флаг `available:false` скрывает преждевременный пункт и запрещает засчитывать локальный клик, но не закрывает цель. Семантический `match` отдельно определяет, что подтверждённая команда действительно выполнила цель. Лудо берёт причину повторного броска из публичной сцены: шестёрка на стартовой картинке не является повторным броском; отключённый переброс не добавляет такую цель. Ятзи различает удержание и освобождение по состоянию кубика до команды. В UNO допустимость команды сама по себе не означает правильный момент для объявления: подсказки ориентируются на открытое окно объявления и конкретного соперника.

Проверены сценарии всех 15 паков: источники/цели Домино и пасьянсов, этапы Акулины/Пексесо, выбор/взятие/дамка в Шашках, расстановка Морского боя, особые клетки и дубль Змей и лестниц, одиночный выбор Крестиков-ноликов; исправленные цепочки перечислены выше. Проверка начального UI всех паков не означает прохождение каждого редкого события в каждой комбинации правил.

Морской бой: после расстановки подсказки предлагают ручное переключение на своё поле, затем на поле соперника и отдельное нажатие кнопки автопереключения. Само открытие поля автоматикой не засчитывается. Нажатие уже выбранной вкладки не закрывает цель. Ревизия цели `enemy` повышена до 2, чтобы исправить ранее засчитанные нажатия активной вкладки.

Общий курсор исключает уже выбранные элементы выбора (`data-view-key`/`data-select` с `aria-pressed`, `aria-selected` или классом выбора) и не засчитывает повторное нажатие. Это относится к типам действия Стихий, фишкам Лудо, поправке хода ЗиЛ и выбору карт/фишек других паков. Команды и переключатели состояния (закрепить/освободить кубик Ятзи, автоматика Морского боя) остаются самостоятельными действиями. Стихии объявляют ревизию 2 для обучения выбору типов действия.

Рыба: список обучения содержит только выбор карты и соперника; автоматический добор исключён и не препятствует завершению обучения.

Лудо: выход с базы по шестёрке (`exit`, ревизия 2) и гарантированный выход после трёх неудач (`exit-guaranteed`) — отдельные цели. Засчитывается подтверждённый выбор фишки с учётом кубика до команды, а не само появление возможности выхода.

Командное Лудо: после финиша всех своих фишек отдельно осваиваются бросок для напарника (`team-roll`) и подтверждённый ход его фишкой (`team-move`). Сам выбор фишки ещё не считается выполненным ходом. До финиша и вне командного режима эти подсказки не появляются.

UNO: объявление использует немедленную подсказку, без ожидания бездействия. Стихии: отмена плана предлагается перед подтверждением второго действия.

### UNO: срочные объявления

`scene.declarationOpen` строится из публичного `data.uno.declarationOpen`, а не удалённых при проекции внутренних `situations`. Подсказка объявления — concurrent + immediate; успешная команда засчитывается по снимку до действия, в том числе вне обычной очереди хода.
