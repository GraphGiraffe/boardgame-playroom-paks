# Персонажи Пексесо — аксессуары и характеры

Восемь листов по шесть цветов. Белый фон, персонажи-стикеры. Растровые эскизы для согласования, в игру не подключены.

- Месяц: прежняя поза и лицо, ночной колпак.
- Треугольник: прежняя поза, озорное лицо с язычком и праздничный колпачок.
- Квадрат: прежняя поза и лицо, круглые прозрачные очки.
- Круг: прежняя поза и лицо, бабочка.
- Звезда: прежняя поза и лицо, корона.
- Прямоугольник: уверенный, чёрные очки, скрещённые руки, ноги расставлены.
- Ромб: застенчивый, сложенные руки, ноги вместе, шарфик.
- Шестиугольник: удивлённый, кепка, рука у козырька и ладонь вверх.

Внутри каждого листа цветовые варианты должны стать точными перекрасками одного исходника при подготовке игровых ассетов. Предыдущие варианты сохранены.
