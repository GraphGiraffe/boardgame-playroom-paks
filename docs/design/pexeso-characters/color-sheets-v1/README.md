# Персонажи Пексесо — цветовые выкладки

Восемь отдельных концепт-листов, по шесть цветовых вариантов на фигуру. Верхний ряд: красный, оранжевый, жёлтый; нижний: зелёный, синий, фиолетовый. Белый фон, бумажные стикеры, лица, тонкие руки и ноги.

Фигуры: месяц, треугольник, квадрат, круг, звезда, прямоугольник, ромб и шестиугольник. Итого 48 вариантов лиц, при двух копиях — 48 пар и 96 игровых карт. Это растровые эскизы для согласования, в игру не подключены. Точная идентичность геометрии и поз цветовых вариантов должна обеспечиваться общим исходником при подготовке ассетов.
