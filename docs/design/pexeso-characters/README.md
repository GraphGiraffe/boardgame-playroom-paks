# Пексесо — персонажи-стикеры

Эскизы нового направления, 2026-10-16. Исходные концепты сохранены для воспроизводимости. Принятые персонажи с аксессуарами подготовлены отдельно как прозрачные ассеты, подключены к аватарам и колоде Пексесо в RC4.

- v1-colored-backgrounds.png — пять мультяшных персонажей с лицами, тонкими руками и ногами на цветных подложках.
- v2-white-backgrounds.png — белые карточки и фон, белая кромка стикеров и мягкая тень.

Последние требования: один персонаж на карте; варианты отличаются цветом вместо количества. Пара состоит из двух полностью одинаковых карт. Персонажи: месяц, треугольник, квадрат, круг, звезда, прямоугольник, ромб и шестиугольник; у каждого 6 цветов. Простые геометрические карточки исключены по решению пользователя; сохраняем только мультяшное направление.

Готовые пакеты: `shared/asset-packs/characters` и `shared/asset-packs/cartoon-deck`. Поза и аксессуар принадлежат персонажу; цвета различают варианты. PNG 512×512 с alpha, runtime WebP 256×256.
