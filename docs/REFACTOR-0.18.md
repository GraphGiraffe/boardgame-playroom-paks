# Паки · рефакторинг 0.18

Утверждённый общий [план приложения и всех 12 паков](https://github.com/GraphGiraffe/boardgame-playroom/blob/dev/docs/AUDIT-0.18.md) хранится в dev приложения. Работа паков — `refactor/0.18-pack-domain`; приложение — `refactor/0.18-engine-foundation`. Выпуск 0.18 ещё не готов; опубликованные версии не изменяются.

## Первый перенос доменного кода

`shared/domain/standard-deck.js` — единый конструктор колоды 36/52/54 без движка, UI, переводов, часов и storage. `create(size, {exclude: []})` возвращает новые объекты в прежнем порядке: ранги по возрастанию, масти ♠/♥/♦/♣, затем красный и чёрный джокеры. Акулина исключает `♣12`; правила пар, квартетов и старшинства принадлежат своим играм.

Исходный manifest объявляет `sharedDomain: ["standard-deck"]`. Сборщик включает модули перед rules.js; распространённый JSON автономен. Node читает модуль через require; браузерный исходный fixture должен загрузить его перед rules. Это два способа загрузки одного исходника, не поддержка двух версий API. Приложение и паки пока имеют два source builder; оба используют одно поле и проверяются на одинаковый результат. Устранение повторных валидаторов — следующий этап контракта контейнера.

Перенесены Дурак, Рыба, Акулина и Пексесо. Форматы состояния, порядок карт и RNG не меняются. Номера опубликованных релизов не перевыпускаются: ветка является разработкой 0.18, новые версии паков назначаются до публикации.

## Следующие этапы

- Реестр всех presets/settings/actions/roles/privacy/result/view для 12 игр, привязка к сценариям приложения.
- Чистые domain-функции и явные события; отдельные presentation-модели и Web renderers.
- Namespace текстов паков в `locales/ru/`; правила хранят ключи/параметры, не локализованное оформление. Переводы входят в автономную поставку.
- Единые RoundToken/Card/Die/Checker/Domino/Ship/ScoreTable/Bubble с палитрой и скинами; geometry и layout отдельно.
- Лудо: старое принятое поле + общий жетон + треугольник на финише. Морской бой: цельная форма корабля, счётчики фаз, устойчивый выбор поля. Ятзи: общая схема категорий и таблица.
- Новый API допускает разрыв форматов без legacy runtime. Полный переход с уведомлением описан в общем плане. Опубликованные теги/байты остаются неизменными.

## Проверки первого этапа

Приложение содержит узкие сценарии `case/domain-foundation`, `case/engine`, `case/rc2-games`: чистая колода/RNG, действующие правила, приватность и результаты. Standalone `bash scripts/codex/check.sh` проверяет упаковку и SHA; полный браузерный/сетевой прогон не является проверкой этого этапа. Проверки и их фактический результат фиксируются в PR, а не объявляются заранее пройденными.


## Палитра Web renderer

Убраны hub overrides `.game-tile` из Шашек, Домино, Дурака, Змей и лестниц и UNO: карточками меню владеет приложение по `manifest.tileTheme`. Это устраняет конфликт нескольких источников цвета при локальной смене темы.

`shared/view-kit.css` использует семантические слоты приложения для tabs/actions/hints/focus. `shared/templates/score-table.css` и таблица Ятзи используют единые `--color-table-{column,header,summary,action,mark,action-mark}`, а также border/text/interaction. Fallback сохраняет автономное отображение без ThemeService; определения палитры и её локальное сохранение принадлежат приложению, не правилам.

Это не замена всех game-specific материалов на AssetResolver. Classic SVG/карты/кубики и принятое старое поле Лудо сохраняются до соответствующего этапа. Нет изменений состояния, RNG, очерёдности, действий или версий опубликованных паков. Перед выпуском этим изменениям будут назначены новые packVersion.

Проверено: standalone `bash scripts/codex/check.sh` (41 JS, 12 паков, SHA 15 файлов), companion `case/rc2-games-browser` (2/2) и `ui/appearance` (3/3, включая контраст Ятзи и сохранность локальной/проецированной сцены).


## Эталон нового API: Крестики-нолики

В ветке подготовлена версия 0.2.0 (engineApi=3, stateVersion=1). Четыре слоя: domain/game.js — чистые правила, presentation/scene.js — переносимая сцена/ссылки сообщений/metrics, locales/ru/game.json — русские тексты, view.js — Web renderer. X принадлежит назначенному первому игроку, независимо от индекса. Правила и бот получают проверяемые immutable данные; UI не пересчитывает победу. Формат board/marks сохранён, сохранения/повтор требуют точную версию пака.

```json
{"sourceModules":{"rules":["domain/game.js","presentation/scene.js"],"view":["presentation/scene.js"],"locales":{"ru":["locales/ru/game.json"]}}}
```

Оба source builder выполняют эту декларацию, поставляют каталоги через PlayroomPackResources.locales и включают модули перед entrypoints. Служебное поле удаляется из поставленного manifest; файлы источников остаются в files. Недопустимые пути/повторы/ключи локалей отклоняются. Результат двух builders проверяется на равенство; общая реализация compiler/validator ещё впереди.

Bootstrap приложения предоставляет временный modelAdapter для старого Session envelope; чистый domain от него не зависит. Raw Node fixture загружает app/model-adapter.js перед rules.js; браузерный источник проходит source builder. Адаптер пока принимает только публичные события. Перенос приватных событий, остальных метрик/результатов и всех прочих игр остаётся в плане; финальный 0.18 не будет включать legacy runtime.

**Стол = Зритель + публичные действия игроков.** Руки рубашками или лицами по общему режиму, публичные кубики видны, обе расстановки Морского боя скрыты. Публичность команды включает её доступность/параметры до выполнения. viewer=-1 остаётся неизменным, actor проверяется отдельно. Эталон объявляет постановку знака public; неприведённые паки пока не получают управление Стола. Сетевые role/actor routing/receipts/history эталонного пака подключены пятым срезом приложения, описанным ниже.


Проверки эталона: `core/model` — 11/11; независимый oracle покрывает по 5478 достижимых позиций/16167 переходов для каждого первого игрока. Совместные engine/session/view-contract/rc2-games/authority — 112/112 до дополнительного защитного случая адаптера; packs-reconcile/domain-foundation/durable-authority/views/rc2-games — 56/56. Сценарии rc2-games-browser + ui/appearance — 6/6, финальный повтор нового браузерного сценария — 1/1. Standalone packs — 12 файлов и SHA 15/15; автономный HTML приложения загружает API 3 из встроенного JSON без HTTP/CDN, page errors 0. Полный цикл и релиз/деплой не запускались; опубликованная пара остаётся 0.17.6 / 0.6.5.


### Сетевой Стол: пятый срез приложения

В companion ветке роль Стола подключена к authority и обычному WebRTC-лобби. Хост выдаёт grant для игровых actor, данные остаются viewer=-1; публичность/легальность проверяется до обычного durable commit. ACK/history не раскрывают руки, игрок не может назначить actor чужого места. Крестики-нолики 0.2.0 — первый проверенный пак; другие игры остаются в зрительском режиме до декларации public actions при переносе domain. UI Стола показывает действия текущего игрока; публичные реакции других акторов нужно включить при переносе соответствующих правил. Сборка пака в этом срезе не менялась. Полный контракт — MULTIVIEW.md приложения, результаты — REFACTOR-0.18-TRACKER.md. Опубликованные версии не изменены.

### Механизмы Session: шестой срез приложения

Companion выделяет History, SessionCodec и typed Events/ModelValues в независимые core-модули. Правила пака не импортируют историю, часы, browser storage или Session; domain возвращает переход/события, а приложение владеет ревизиями, сериализацией и durable commit. CommonJS fixture GameModel требует model-runtime (он разрешает зависимости сам); Web/source bootstrap загружает model-values/events перед ним. Автономный JSON пака не должен включать копии host runtime.

Схема typed events/publicEvent эталона не меняется. Временный model-adapter по-прежнему принимает только публичные события; общий приватный журнал и canonical event IDs ещё не подключены. Форматы Session 1/2 остаются промежуточными; это не обещание их поддержки в финальном 0.18. Исполняемые исходники и версии паков в этом срезе не меняются. Выбранные совместные проверки Session/model/authority/правил/восстановления — 147/147, отдельная PWA-проверка — 1/1; подробности и команды в REFACTOR-0.18-TRACKER.md приложения.


### Седьмой срез: Ятзи и полный typed event projector

Текущий SDK core/model-registration.js заменяет app/model-adapter.js. Приватные typed события теперь сохраняются с ID/revision у хоста, проектируются до перевода/звука/replay и проверены; прежний защитный отказ адаптера удалён. Node registration вызывает engine.registerModel. Domain не импортирует приложение/renderer.

Ятзи 0.2.0 / API 3 разделён на domain/categories, domain/game, presentation/scene и locales/ru/game.json. Схема категорий одна, score previews числовые, RNG явный, Web не разбирает label. Три броска, hold/release, бонус/ноль/ничья сохранены; все команды публичны для Стола. Capabilities объявляют quietActions и policy UI; Морской бой объявляет viewStateScope=match и minimumVisibleMs по фазе. Общий runtime больше не узнаёт их по ID.

Бот Пексесо исправлен по A18: неизвестные лица не участвуют даже в преднамеренном промахе. Проверка перестановки нераскрытых карт подтверждает одинаковый выбор. Другие десять игр, shared компоненты/AssetResolver, весь русский каталог и финальный переход ещё требуют работы. Исправления не публикуются под прежними версиями.


### Canonical компоненты: восьмой срез

shared/components/round-token.js — рабочий источник RoundToken, firstSymbol и числовых знаков. Оба builder встраивают его перед view-kit; Лудо/Змеи вызывают этот же компонент и не содержат запасных SVG. Приложение включает закреплённую копию с digest/provenance, проверяемыми source builder. Изменения вносить в canonical файл, затем обновлять host copy явной сборкой с companion source. Геометрия/шрифт принятых элементов сохранены; правила масштаба/стопки/веера остаются в shared/assets/README.md.

Совместная byte/digest parity и действующие модели/сцены проверены 69/69. Остальные семьи ассетов и AssetResolver пока не объявляются полностью перенесёнными.
