# Паки · рефакторинг 0.18

Утверждённый общий [план приложения и всех 12 паков](https://github.com/GraphGiraffe/boardgame-playroom/blob/dev/docs/AUDIT-0.18.md) хранится в dev приложения. Работа паков — `refactor/0.18-pack-domain`; приложение — `refactor/0.18-engine-foundation`. Выпуск 0.18 ещё не готов; опубликованные версии не изменяются.

## Первый перенос доменного кода

`shared/domain/standard-deck.js` — единый конструктор колоды 36/52/54 без движка, UI, переводов, часов и storage. `create(size, {exclude: []})` возвращает новые объекты в прежнем порядке: ранги по возрастанию, масти ♠/♥/♦/♣, затем красный и чёрный джокеры. Акулина исключает `♣12`; правила пар, квартетов и старшинства принадлежат своим играм.

Исходный manifest объявляет `sharedDomain: ["standard-deck"]`. Сборщик включает модули перед rules.js; распространённый JSON автономен. Node читает модуль через require; браузерный исходный fixture должен загрузить его перед rules. Это два способа загрузки одного исходника, не поддержка двух версий API. Приложение и паки пока имеют два source builder; оба используют одно поле и проверяются на одинаковый результат. Устранение повторных валидаторов — следующий этап контракта контейнера.

Перенесены Дурак, Рыба, Акулина и Пексесо. Форматы состояния, порядок карт и RNG не меняются. Номера опубликованных релизов не перевыпускаются: ветка является разработкой 0.18, новые версии паков назначаются до публикации.

## Следующие этапы

- Реестр всех presets/settings/actions/roles/privacy/result/view для 12 игр, привязка к сценариям приложения.
- Чистые domain-функции и явные события; отдельные presentation-модели и Web renderers.
- Namespace текстов паков в `locales/ru/`; правила хранят ключи/параметры, не локализованное оформление. Переводы входят в автономную поставку.
- Единые RoundToken/Card/Die/Checker/Domino/Ship/ScoreTable/Bubble с палитрой и скинами; geometry и layout отдельно.
- Лудо: старое принятое поле + общий жетон + треугольник на финише. Морской бой: цельная форма корабля, счётчики фаз, устойчивый выбор поля. Ятзи: общая схема категорий и таблица.
- Новый API допускает разрыв форматов без legacy runtime. Полный переход с уведомлением описан в общем плане. Опубликованные теги/байты остаются неизменными.

## Проверки первого этапа

Приложение содержит узкие сценарии `case/domain-foundation`, `case/engine`, `case/rc2-games`: чистая колода/RNG, действующие правила, приватность и результаты. Standalone `bash scripts/codex/check.sh` проверяет упаковку и SHA; полный браузерный/сетевой прогон не является проверкой этого этапа. Проверки и их фактический результат фиксируются в PR, а не объявляются заранее пройденными.
