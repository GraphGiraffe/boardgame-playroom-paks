# Окружение разработки коллекции 0.7

Нужны Python 3.9+ и Node.js 22+. Для совместной браузерной проверки — checkout приложения 0.18, его npm-зависимости и Chromium. Сначала найдите фактические корни обоих репозиториев по Git remotes; не предполагайте путь `/workspace` или соседство каталогов. Сохраняйте текущую ветку и чужие изменения.

## Только коллекция

```sh
bash scripts/codex/setup.sh
bash scripts/codex/check.sh
```

Проверяются синтаксис, сборка контейнеров и SHA256. Здесь нет npm-зависимостей; этот результат не подтверждает gameplay или браузер.

## Вместе с приложением

Задайте `APP_CHECKOUT` реальному абсолютному пути checkout приложения:

```sh
bash scripts/codex/setup.sh --app-dir "${APP_CHECKOUT:?Укажите путь к checkout приложения}"
bash scripts/codex/check.sh --full --app-dir "$APP_CHECKOUT"
```

Полный режим использует именно исходники текущей коллекции, а не последнюю удалённую сборку. Для адресной задачи после подготовки выберите нужные blocks/case в runner приложения; [TESTING](https://github.com/GraphGiraffe/boardgame-playroom/blob/main/docs/TESTING.md).

Подготовка приложения использует закреплённый npm ci и выбирает Chromium/Chrome либо устанавливает браузер Playwright. `CHROME_BIN` переопределяет путь браузера. Системные библиотеки устанавливаются только по явному `--install-system-deps`; глобальные настройки сети и работающие службы не менять.

Для preview используйте `bash scripts/codex/serve.sh` из приложения. По умолчанию адрес `127.0.0.1:4173`; сначала проверьте занятость порта и переиспользуйте подходящий сервер. Приложению для локальной игры не нужны API-сервер, база или секреты. Нужны доступ к исходникам приватных репозиториев и разрешённые загрузки зависимостей; токены не помещать в файлы проекта, логи или артефакты.

После изменения зависимостей повторите подготовку окружения. [AGENTS](../AGENTS.md), [руководство автора](AUTHORING.md), [окружение приложения](https://github.com/GraphGiraffe/boardgame-playroom/blob/main/docs/CODEX-CLOUD.md).
