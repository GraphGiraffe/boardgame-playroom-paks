# Игровая коллекция ХОД

Независимые паки настольных игр для [приложения ХОД](https://github.com/GraphGiraffe/boardgame-playroom). Каждый пак содержит метаданные, правила, представление, материалы и поведение ботов. Общие компоненты и исходные ассеты находятся в `shared/`.

## Использование

Откройте [сайт](https://graphgiraffe.github.io/playroom-hod-test/) и установите игры из каталога приложения. Поддерживаются актуальные приложение и коллекция. Старые версии паков отдельно не сопровождаются.

## Разработка

Правила и метаданные игры находятся в `packs/<id>/`; `manifest.json` — источник, `manifest.js` генерируется сборщиком.

Локальная сборка и проверки: [CONTRIBUTING](CONTRIBUTING.md). Правила и UI проверяются с совместимой копией приложения; полный набор тестов автоматически не запускается.
